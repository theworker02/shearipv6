# shearipv6

Shear CSV/TSV ipv6 tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/shearipv6/

## Install / run

```bash
git clone https://github.com/theworker02/shearipv6.git
cd shearipv6
node src/cli.js
node --test
```
